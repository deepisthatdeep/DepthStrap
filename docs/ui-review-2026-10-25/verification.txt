Failures investigated during verification
The first sandboxed recovery run could not access its synthetic cookie fixture through native Windows APIs. The same isolated suite passed outside those restrictions, then passed again against the final build.
The first sandboxed package publish stopped during restore; the publish succeeded with normal runtime-pack/cache access.
An initial test compile lacked an extension-method import; this was fixed before the final build.
The new popup-command test exposed detached DataContext behavior; the popup now binds explicitly through PlacementTarget.
A compact-sidebar width assertion exposed a fixed-width override; removing it restores the saved compact state.
Native navigation does not initialize normally in a detached visual; that unsupported assertion was replaced with explicit preview state and no native-navigation claim.
